# AudioTap POC — tester builds

Download the latest build: **[AudioTapPOC.dmg](https://github.com/Shaydu/audiotap-releases/releases/latest)**

- macOS 14.2 or later, Apple Silicon (M1 or later).
- Signed and notarized: open the disk image, drag AudioTap POC to Applications, open it.
- Every build's changes are in its release notes and in the app under Help → What's New…
- Report problems from inside the app: Help → Report a Bug…

This repository holds release downloads only.
